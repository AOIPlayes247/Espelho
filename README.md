# Pasta /downloads
- `agent.py`: agente do Windows (recebe os comandos do site).
- `INICIAR-PC.bat`: instala as dependências e roda o agente (precisa do Python: python.org, marcando "Add Python to PATH").

Deixe os dois na mesma pasta. No primeiro uso o agente pede o endereço do seu site (ex.: https://usuario.github.io) e o salva em `origin.txt`.
